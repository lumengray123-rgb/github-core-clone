A GitHub-compatible git forge in Node 22 / TypeScript, zero dependencies: git smart HTTP (protocol v2 + v0, packfiles with deltas), REST v3, GraphQL v4, and an MCP server, all on one deterministic in-memory store. Kit suite: 120/120 conformance, 15/15 MCP.

## Run it

```sh
node main.ts
```

The trial harness sets `MAKEFUN_ENV_URL`; the entry binds an ephemeral port, registers it, and serves until the trial ends.
